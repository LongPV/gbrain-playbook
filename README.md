# gbrain-playbook

A public, living collection of engineering and AI-practice notes — curated
from my personal knowledge brain ([GBrain](https://github.com/garrytan/gbrain))
rather than written from scratch. Each entry starts as a fact or decision
captured during real work, then gets promoted here once it's generalizable
enough to be useful to someone else.

## Structure

| Folder | Covers |
|---|---|
| [`engineering/`](engineering/) | Production software engineering — reliability, scalability, cost/perf tradeoffs |
| [`ai-agents/`](ai-agents/) | Agent architecture — context management, tool design, planning vs. execution |
| [`evals/`](evals/) | Evaluation & reliability practices for LLM-based systems |
| [`gbrain/`](gbrain/) | Notes on building and operating a personal knowledge brain |

Each folder holds standalone write-ups — one practice or lesson per file, with
enough context to be useful without the rest of the repo.
